# Как обновить баланс всех пользователей до 1000 фишек

## Проблема
Пользователи все еще имеют старый баланс (например, 107500 фишек), а не новый (1000 фишек).

## Решение

### Способ 1: Автоматическое обновление при запуске
1. Найдите в сцене `MainMenu` объект с компонентом `MainMenuUIController`
2. В Inspector найдите секцию "Обновление баланса"
3. Убедитесь, что галочка `Update Users Balance On Start` включена
4. Установите `New Default Balance` = 1000
5. Запустите игру - баланс всех пользователей обновится автоматически

### Способ 2: Ручное обновление через контекстное меню
1. Найдите в сцене объект с компонентом `MainMenuUIController`
2. Нажмите правой кнопкой мыши на компонент в Inspector
3. Выберите "Обновить баланс всех пользователей"
4. Проверьте консоль - там будет информация об обновлении

### Способ 3: Через отдельный компонент UserBalanceUpdater
1. Создайте пустой GameObject в сцене
2. Добавьте компонент `UserBalanceUpdater`
3. Нажмите ПКМ на компонент → "Обновить баланс всех пользователей"

## Что происходит при обновлении

1. **Загружаются все профили пользователей** из сохраненных файлов
2. **Устанавливается новый баланс** (1000 фишек) для каждого пользователя
3. **Сбрасываются недельные лимиты** пополнения
4. **Сохраняются обновленные профили** в файлы
5. **Обновляется текущий пользователь** в памяти (если авторизован)
6. **Обновляется интерфейс** с новым балансом

## Проверка результата

После обновления в консоли Unity вы увидите сообщения типа:
```
MainMenuUIController: Обновлен пользователь artem: 107500 -> 1000 фишек
MainMenuUIController: Обновлен пользователь victor: 23702 -> 1000 фишек
MainMenuUIController: Обновление завершено. Обновлено 2 из 2 пользователей
```

В игре баланс пользователей должен показывать 1000 фишек.

## Настройки

### В MainMenuUIController:
- `Update Users Balance On Start` - автоматически обновлять при запуске
- `New Default Balance` - новый баланс для всех пользователей (1000)

### Если нужно отключить автоматическое обновление:
Снимите галочку `Update Users Balance On Start` после первого запуска, чтобы баланс не сбрасывался каждый раз.

## Безопасность

- Система создает резервные копии профилей перед изменением
- Все изменения логируются в консоль Unity
- Если произойдет ошибка, старые профили останутся нетронутыми

## Устранение проблем

### Если баланс не обновился:
1. Проверьте консоль Unity на наличие ошибок
2. Убедитесь, что файлы профилей не заблокированы другими процессами
3. Проверьте права доступа к папке с сохранениями
4. Попробуйте запустить обновление вручную через контекстное меню

### Если нужно вернуть старые балансы:
1. Найдите папку с резервными копиями профилей
2. Восстановите нужные файлы из бэкапа
3. Перезапустите игру
