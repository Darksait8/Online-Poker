# 🔧 Решение проблем с подключением

## ❌ Ошибка: "Подключение не установлено, т.к. конечный компьютер отверг запрос на подключение"

Эта ошибка означает, что клиент не может подключиться к серверу.

### ✅ Решение:

#### 1. Убедитесь, что сервер запущен

**На устройстве с сервером:**
```bash
cd Server
dotnet run
```

Вы должны увидеть:
```
🎮 Покерный сервер запущен на порту 8888
Ожидание подключений...
```

#### 2. Проверьте IP-адрес и порт

**В Unity:**
- Откройте ConnectionManager в Inspector
- Проверьте поле "Server Host":
  - `localhost` - если сервер на том же компьютере
  - `192.168.0.121` - ваш локальный IP (из ipconfig)
  - Другой IP - если сервер на другом устройстве
- Проверьте поле "Server Port": должно быть `8888`

#### 3. Отключите автоматическое подключение

**Проблема:** PokerClient пытается подключиться автоматически при старте, даже если сервер не запущен.

**Решение:**
1. Найдите GameObject с компонентом `PokerClient` в сцене
2. В Inspector найдите поле **"Auto Connect On Start"**
3. **Снимите галочку** (должно быть `false`)
4. Теперь подключение будет происходить только при нажатии кнопки "Подключиться"

#### 4. Проверьте файрвол

**Windows:**
- Откройте "Брандмауэр Защитника Windows"
- Разрешите входящие подключения для порта 8888
- Или временно отключите файрвол для теста

**Linux:**
```bash
sudo ufw allow 8888/tcp
```

#### 5. Правильный порядок действий

1. **Сначала запустите сервер** (в терминале)
2. **Затем запустите Unity** и игру
3. **В игре нажмите "Подключиться"**

## ⚠️ Предупреждения MainMenuUIController

Эти предупреждения не критичны, но их можно исправить:

### "User Balance Text не привязан"

**Решение:**
1. Найдите GameObject с `MainMenuUIController`
2. В Inspector найдите поле **"User Balance Text"** или **"User Balance Text TMP"**
3. Перетащите туда Text или TextMeshProUGUI компонент из UI

### "Replenish Button не привязана"

**Решение:**
1. Найдите GameObject с `MainMenuUIController`
2. В Inspector найдите поле **"Replenish Button"**
3. Перетащите туда Button из UI

**Примечание:** Если эти элементы не используются, предупреждения можно игнорировать.

## 🎯 Быстрая проверка

### Чек-лист:

- [ ] Сервер запущен и показывает "Ожидание подключений..."
- [ ] В Unity поле "Auto Connect On Start" = `false` (отключено)
- [ ] IP-адрес правильный (`localhost` для локального сервера)
- [ ] Порт правильный (`8888`)
- [ ] Файрвол не блокирует подключение
- [ ] Нажата кнопка "Подключиться" в игре

## 💡 Советы

1. **Всегда запускайте сервер первым** - это главное правило
2. **Используйте `localhost`** для локального тестирования
3. **Проверяйте Console в Unity** - там будут подробные сообщения об ошибках
4. **Не включайте Auto Connect** - лучше подключаться вручную через UI

## 🔍 Отладка

Если проблема остается:

1. **Проверьте логи сервера:**
   - В консоли сервера должны появляться сообщения о подключениях

2. **Проверьте логи Unity:**
   - Откройте Console (Window → General → Console)
   - Ищите сообщения с префиксом `🔌` или `❌`

3. **Проверьте сеть:**
   ```bash
   # Windows
   ping localhost
   
   # Проверка порта (если установлен telnet)
   telnet localhost 8888
   ```

4. **Попробуйте другой порт:**
   - Измените порт в сервере и клиенте на другой (например, 9999)
   - Убедитесь, что порт не занят другим приложением
