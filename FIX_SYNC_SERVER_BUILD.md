# Исправление ошибки сборки сервера синхронизации

## Проблема

Ошибка: "Для программы определено несколько точек входа"

Это происходит потому, что проект `SyncServer` ссылается на `PokerServer.csproj`, который содержит `Program.cs`, и у самого `SyncServer` тоже есть `Program.cs`.

## Решение

Проект `SyncServer` теперь использует только `SimpleSyncServer.cs` без ссылки на основной проект, что устраняет конфликт.

## Запуск

Теперь сервер синхронизации можно запустить так:

```bash
cd Server\SyncServer
dotnet run -- --port 8889 --key "ваш-ключ"
```

**Важно:** Используйте `--` (два дефиса) после `dotnet run`!

## Альтернативный способ

С переменными окружения:

**Windows (PowerShell):**
```powershell
cd Server\SyncServer
$env:SYNC_PORT=8889
$env:SYNC_API_KEY="ваш-ключ"
dotnet run
```

**Windows (CMD):**
```cmd
cd Server\SyncServer
set SYNC_PORT=8889
set SYNC_API_KEY=ваш-ключ
dotnet run
```
