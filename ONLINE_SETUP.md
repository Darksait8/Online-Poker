# 🌐 Руководство по настройке онлайн-игры

Это руководство поможет вам настроить онлайн-режим для вашей покерной игры.

## 📋 Что было добавлено

### Серверная часть (`Server/`)
- `PokerServer.cs` - основной сервер
- `ClientConnection.cs` - обработка подключений клиентов
- `GameSession.cs` - управление игровой сессией
- `Program.cs` - точка входа сервера

### Клиентская часть (`Assets/Scripts/`)
- `NetworkGameManager.cs` - синхронизация онлайн-игры
- Обновлен `ActionPanelController.cs` - отправка действий на сервер
- Обновлен `PokerClient.cs` - обработка сообщений о картах

## 🚀 Быстрый старт

### Шаг 1: Запуск сервера

1. Откройте терминал/командную строку
2. Перейдите в папку `Server`
3. Выполните:

```bash
dotnet build
dotnet run
```

**Примечание:** Если у вас установлен .NET 8.0, а проект требует 6.0, проект уже обновлен на .NET 8.0. Если возникнут проблемы, выполните:
```bash
dotnet clean
dotnet restore
dotnet build
dotnet run
```

Сервер запустится на порту **8888** (по умолчанию).

### Шаг 2: Настройка Unity клиента

1. Откройте сцену с игрой в Unity
2. Найдите объект с компонентом `GameManager`
3. Добавьте компонент `NetworkGameManager` на тот же объект
4. В инспекторе назначьте:
   - `Poker Client` - компонент PokerClient
   - `Game Manager` - компонент GameManager

### Шаг 3: Включение онлайн-режима

#### Вариант A: Через код

В вашем скрипте меню или при запуске игры:

```csharp
var networkManager = FindObjectOfType<NetworkGameManager>();
if (networkManager != null)
{
    networkManager.EnableOnlineMode("localhost", 8888);
}
```

#### Вариант B: Через ConnectionManager

Если у вас есть UI для подключения:
1. Используйте существующий `ConnectionManager`
2. Он автоматически подключится через `PokerClient`

### Шаг 4: Тестирование

1. Запустите сервер
2. Запустите 2 экземпляра игры (или на разных компьютерах)
3. Оба клиента должны подключиться к серверу
4. Игра начнется автоматически при наличии 2+ игроков

## 🔧 Настройка для сети

### Локальная сеть

Если клиенты на разных компьютерах в одной сети:

1. **На сервере:**
   - Узнайте IP-адрес компьютера с сервером
   - Windows: `ipconfig` в командной строке
   - Linux/Mac: `ifconfig` или `ip addr`

2. **В Unity:**
   - Вместо `"localhost"` используйте IP-адрес сервера
   - Например: `networkManager.EnableOnlineMode("192.168.1.100", 8888)`

### Интернет (требует настройки)

Для игры через интернет нужно:

1. **Настроить порт на роутере:**
   - Откройте порт 8888 (или другой) для TCP
   - Направьте его на IP компьютера с сервером

2. **Использовать внешний IP:**
   - Узнайте внешний IP (например, через whatismyip.com)
   - Используйте его в клиентах

⚠️ **Внимание:** Для продакшена нужен более безопасный протокол (HTTPS/WSS) и защита от DDoS.

## 📝 Интеграция с существующим кодом

### GameManager

`NetworkGameManager` автоматически синхронизирует:
- Список игроков
- Действия игроков
- Состояние игры

Ваш существующий `GameManager` продолжит работать локально, но также будет получать обновления от сервера.

### ActionPanelController

Действия игрока автоматически отправляются на сервер при:
- Fold
- Call/Check
- Raise/Bet

Никаких дополнительных изменений не требуется.

## 🐛 Решение проблем

### Сервер не запускается

- Проверьте, что порт 8888 не занят другим приложением
- Убедитесь, что установлен .NET 6.0+
- Проверьте права доступа (на Linux может потребоваться sudo)

### Клиент не подключается

- Проверьте, что сервер запущен
- Убедитесь, что IP-адрес и порт правильные
- Проверьте файрвол (может блокировать соединение)

### Игра не синхронизируется

- Убедитесь, что `NetworkGameManager` добавлен в сцену
- Проверьте, что `PokerClient` и `GameManager` назначены в инспекторе
- Посмотрите логи Unity Console на ошибки

## 🔒 Безопасность

Текущая реализация упрощена для демонстрации. Для продакшена рекомендуется:

1. **Шифрование:** Использовать TLS/SSL для соединений
2. **Аутентификация:** Добавить систему логинов/паролей
3. **Валидация:** Проверять все действия на сервере
4. **Защита от читов:** Сервер должен быть единственным источником истины
5. **Rate limiting:** Ограничить частоту запросов от клиентов
