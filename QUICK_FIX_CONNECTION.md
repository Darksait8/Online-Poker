# ⚡ Быстрое решение проблемы подключения

## ❌ Ошибка: "Сервер не запущен или недоступен"

### ✅ Пошаговое решение:

#### Шаг 1: Проверьте, что сервер запущен

**Откройте терминал/командную строку и выполните:**

```bash
cd C:\Users\артем\Desktop\Server
dotnet run
```

**Вы должны увидеть:**
```
🎮 Покерный сервер запущен на порту 8888
Ожидание подключений...
```

**⚠️ ВАЖНО:** Оставьте это окно открытым! Сервер должен работать постоянно.

#### Шаг 2: Проверьте настройки в Unity

1. **Найдите ConnectionManager** в сцене
2. **В Inspector проверьте:**
   - **Server Host Input** → должно быть `localhost` (если сервер на том же компьютере)
   - **Server Port Input** → должно быть `8888`

#### Шаг 3: Правильный порядок действий

1. ✅ **Сначала** запустите сервер (терминал с `dotnet run`)
2. ✅ **Затем** запустите Unity и игру
3. ✅ **В игре** нажмите кнопку "Подключиться"

#### Шаг 4: Если все еще не работает

**Проверьте файрвол:**

**Windows:**
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Правила для входящих подключений → Создать правило
4. Порт → TCP → 8888 → Разрешить подключение

**Или временно отключите файрвол для теста**

## 🔍 Диагностика

### Проверка 1: Сервер запущен?

**В терминале сервера должно быть:**
```
🎮 Покерный сервер запущен на порту 8888
Ожидание подключений...
```

Если этого нет → сервер не запущен!

### Проверка 2: Правильный IP?

- **`localhost`** или **`127.0.0.1`** - для сервера на том же компьютере
- **`192.168.x.x`** - для сервера в локальной сети
- **Другой IP** - для удаленного сервера

### Проверка 3: Правильный порт?

Должно быть **`8888`** (как в сервере)

### Проверка 4: Файрвол?

Попробуйте временно отключить файрвол Windows для теста

## 💡 Частые ошибки

### ❌ "Сервер не запущен"
**Решение:** Запустите сервер в терминале (`dotnet run`)

### ❌ "Connection refused"
**Решение:** 
- Проверьте, что сервер запущен
- Проверьте IP-адрес (`localhost` для локального сервера)
- Проверьте порт (`8888`)

### ❌ "Timeout"
**Решение:**
- Проверьте IP-адрес (может быть неправильный)
- Проверьте файрвол
- Проверьте сеть

## 🎯 Чек-лист

Перед подключением убедитесь:

- [ ] Сервер запущен и показывает "Ожидание подключений..."
- [ ] В Unity поле "Server Host" = `localhost` (для локального сервера)
- [ ] В Unity поле "Server Port" = `8888`
- [ ] Файрвол не блокирует порт 8888
- [ ] Нажата кнопка "Подключиться" в игре

## 📞 Если ничего не помогает

1. **Перезапустите сервер:**
   - Закройте терминал с сервером
   - Откройте новый терминал
   - `cd Server`
   - `dotnet run`

2. **Перезапустите Unity:**
   - Закройте Unity
   - Откройте снова
   - Запустите игру

3. **Проверьте логи:**
   - В Unity Console ищите сообщения с `🔌` или `❌`
   - В терминале сервера должны появляться сообщения о подключениях

---

**После выполнения этих шагов подключение должно работать! 🎮**
