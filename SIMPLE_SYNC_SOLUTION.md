# Простое решение проблемы синхронизации

## Проблема

Ошибка "Отказано в доступе" при запуске сервера синхронизации - это проблема прав Windows для HttpListener.

## Самое простое решение

**Используйте другой порт выше 1024:**

```bash
cd Server\SyncServer
dotnet run -- --port 9000 --key "piska"
```

Это должно работать без прав администратора!

## Затем настройте игровой сервер

В другом окне терминала:

```bash
cd Server
set POKER_SYNC_URL=http://localhost:9000
set POKER_SYNC_API_KEY=piska
dotnet run --sync-env
```

## Порядок запуска

**Для синхронизации:**
1. Сначала запустите SyncServer (порт 9000)
2. Потом запустите PokerServer с синхронизацией

**Но для решения ошибки "Отказано в доступе" порядок не важен** - это проблема прав Windows, не порядка запуска.

## Альтернатива: Без синхронизации

Если не хотите настраивать синхронизацию прямо сейчас, можно просто запустить обычный сервер:

```bash
cd Server
dotnet run
```

Пользователи будут храниться локально на этом сервере. Синхронизацию можно настроить позже.
