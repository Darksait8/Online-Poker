# Быстрая настройка синхронизации

## Простое решение (5 минут)

### 1. Запустите сервер синхронизации на одном ПК

```bash
cd Server
dotnet run --sync-server --port 8889 --key "мой-секретный-ключ"
```

Или создайте отдельный проект для сервера синхронизации (см. `Server/SyncServer/Program.cs`)

### 2. Узнайте IP-адрес этого ПК

**Windows:**
```cmd
ipconfig
```
Найдите IPv4 адрес (например, `192.168.1.100`)

**Linux/Mac:**
```bash
hostname -I
```

### 3. На всех других устройствах установите переменные окружения

**Windows (PowerShell):**
```powershell
$env:POKER_SYNC_URL="http://192.168.1.100:8889"
$env:POKER_SYNC_API_KEY="мой-секретный-ключ"
```

**Windows (CMD):**
```cmd
set POKER_SYNC_URL=http://192.168.1.100:8889
set POKER_SYNC_API_KEY=мой-секретный-ключ
```

**Linux/Mac:**
```bash
export POKER_SYNC_URL="http://192.168.1.100:8889"
export POKER_SYNC_API_KEY="мой-секретный-ключ"
```

### 4. Запустите игровые серверы с синхронизацией

```bash
cd Server
dotnet run --sync-env
```

## Готово! 

Теперь все пользователи автоматически синхронизируются между всеми серверами.

## Проверка

1. Зарегистрируйте пользователя на одном устройстве
2. Попробуйте войти с этого же аккаунта на другом устройстве
3. Должно работать без ручного обновления!

## Если сервер синхронизации на другом ПК

Убедитесь, что:
- Порт 8889 открыт в файрволе
- Сервер синхронизации доступен по сети
- Используйте правильный IP-адрес (не localhost)

## Безопасность

⚠️ **Измените ключ по умолчанию!** Используйте сложный ключ:
```bash
# Linux/Mac
openssl rand -hex 32

# Windows (PowerShell)
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 32 | % {[char]$_})
```
