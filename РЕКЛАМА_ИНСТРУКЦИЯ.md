# Система рекламы при пополнении баланса

## Что реализовано

Добавлена система показа рекламы при пополнении баланса в онлайн покере. Реклама показывается в зависимости от суммы пополнения:

### Логика показа рекламы:

1. **Малые суммы (500, 1000, 2500 фишек)**: 
   - Показывается случайная реклама (видео ИЛИ фото)
   - Длительность: 10 секунд
   - После просмотра пользователь может закрыть рекламу кнопкой "X"

2. **Большие суммы (5000, 10000 фишек)**:
   - Показывается И видео И фото последовательно
   - Каждое по 10 секунд
   - После просмотра пользователь может закрыть рекламу кнопкой "X"

## Файлы, которые были изменены/созданы:

1. **Assets/Scripts/UI/AdvertisementPanel.cs** - Новый класс для показа рекламы
2. **Assets/Scripts/MainMenuUIController.cs** - Интеграция рекламы в процесс пополнения
3. **Assets/StreamingAssets/advertisement/** - Папка для рекламных материалов

## Настройка рекламных материалов:

### ВАЖНО! Нужно вручную скопировать файлы:

1. Скопируйте `advertisement/IMG_4134.MP4` в `Assets/StreamingAssets/advertisement/`
2. Скопируйте `advertisement/photo_2025-11-21_17-42-09.jpg` в `Assets/StreamingAssets/advertisement/`

### Добавление новых рекламных материалов:

1. Поместите видеофайлы в `Assets/StreamingAssets/advertisement/`
2. Поместите изображения в `Assets/StreamingAssets/advertisement/`
3. В коде `AdvertisementPanel.cs` обновите массивы:
   - `adVideoFiles` - для видео файлов
   - `adImageFiles` - для изображений

## Как это работает:

1. Пользователь нажимает "Пополнить" в главном меню
2. Выбирает сумму пополнения
3. Нажимает "Пополнить"
4. **НОВОЕ**: Показывается реклама в зависимости от суммы
5. После просмотра рекламы (10 сек + возможность закрыть) баланс пополняется

## Настройки рекламы:

В классе `AdvertisementPanel` можно настроить:
- `adDuration` - длительность показа рекламы (по умолчанию 10 секунд)
- `adVideoFiles` - список видеофайлов для рекламы
- `adImageFiles` - список изображений для рекламы

## Поддерживаемые форматы:

- **Видео**: MP4, AVI, MOV (поддерживаемые Unity VideoPlayer)
- **Изображения**: JPG, PNG, GIF

## Логика определения "больших" сумм:

Суммы >= 5000 фишек считаются "большими" и показывают полную рекламу (видео + фото).
Это можно изменить в методе `ShowRandomAd()` в `AdvertisementPanel.cs`.
