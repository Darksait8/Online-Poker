# Система баланса и недельных лимитов

## Что изменено

### 1. Стартовый баланс
- **Старое значение**: 10000 фишек
- **Новое значение**: 1000 фишек
- Все новые пользователи получают 1000 фишек при регистрации

### 2. Недельные лимиты пополнения
- **Максимум пополнений в неделю**: 10000 токенов
- Неделя считается с понедельника по воскресенье
- Лимит автоматически сбрасывается каждый понедельник

## Новые возможности

### Отслеживание пополнений
- Система автоматически отслеживает все пополнения пользователя
- Показывает оставшийся лимит на текущую неделю
- Блокирует пополнения при превышении лимита

### Информация в интерфейсе
В панели пополнения теперь отображается:
```
Текущий баланс: 1 500
Недельный лимит: 7 500 из 10 000
```

## Как обновить существующих пользователей

### Автоматическое обновление:
1. Добавьте компонент `UserBalanceUpdater` на любой GameObject в сцене
2. Поставьте галочку `Update On Start`
3. Запустите игру - все пользователи будут обновлены автоматически

### Ручное обновление:
1. В Inspector найдите компонент `UserBalanceUpdater`
2. Нажмите правой кнопкой мыши
3. Выберите "Обновить баланс всех пользователей"

### Через консоль Unity:
```csharp
// Найти компонент и обновить всех пользователей
FindObjectOfType<UserBalanceUpdater>()?.UpdateAllUsersBalance();
```

## Логика работы лимитов

### Проверка при пополнении:
```csharp
// Пример проверки
UserProfile user = AuthManager.CurrentUser;
int depositAmount = 2000;

if (user.CanDeposit(depositAmount))
{
    user.AddDeposit(depositAmount); // Пополняет и обновляет счетчик
    // Баланс пополнен успешно
}
else
{
    int remaining = user.GetRemainingWeeklyDeposit();
    // Показать ошибку: "Осталось на эту неделю: {remaining} фишек"
}
```

### Автоматический сброс лимитов:
- Система автоматически проверяет дату при каждом пополнении
- Если началась новая неделя (понедельник), лимит сбрасывается
- Не требует дополнительных действий от разработчика

## Полезные команды

### В компоненте UserBalanceUpdater:

1. **"Обновить баланс всех пользователей"**
   - Устанавливает всем пользователям баланс 1000
   - Сбрасывает недельные лимиты

2. **"Сбросить недельные лимиты"**
   - Только сбрасывает лимиты, не меняет баланс

3. **"Показать статистику пользователей"**
   - Выводит в консоль информацию о всех пользователях
   - Показывает балансы и использованные лимиты

## Безопасность

- Все изменения сохраняются в файлы профилей пользователей
- Создаются резервные копии перед изменениями
- Система устойчива к сбоям и перезапускам игры
- Лимиты работают даже после переустановки игры (если сохранены профили)
