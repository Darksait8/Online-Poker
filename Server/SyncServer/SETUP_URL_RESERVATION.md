# Настройка резервации URL для доступа из сети

## Проблема

По умолчанию сервер синхронизации слушает только `localhost`, что означает доступ только с того же компьютера.

## Решение 1: Использование localhost (по умолчанию)

Сервер работает на `localhost:8889`. Это безопасно и не требует прав администратора.

**Для доступа с других устройств в локальной сети** нужно использовать IP-адрес сервера, но для этого требуется резервация URL.

## Решение 2: Резервация URL для доступа из сети

Если нужно, чтобы сервер был доступен из сети, выполните резервацию URL:

### Windows (требует прав администратора)

Откройте PowerShell или CMD **от имени администратора** и выполните:

```powershell
netsh http add urlacl url=http://+:8889/ user=Everyone
```

Или для конкретного пользователя:
```powershell
netsh http add urlacl url=http://+:8889/ user=%USERNAME%
```

### Проверка резерваций

```powershell
netsh http show urlacl
```

### Удаление резервации

```powershell
netsh http delete urlacl url=http://+:8889/
```

## Решение 3: Изменить код для использования всех интерфейсов

Если вы настроили резервацию URL, можно изменить код в `SimpleSyncServer.cs`:

```csharp
listener.Prefixes.Add($"http://+:{port}/");  // Доступ из сети
```

Или:
```csharp
listener.Prefixes.Add($"http://*:{port}/");  // Доступ из сети (альтернатива)
```

## Важно

- **Резервация URL** требуется только для доступа из сети
- Для локального использования (`localhost`) резервация не нужна
- После резервации перезапустите сервер

## Проверка доступа

После настройки проверьте доступность:

```bash
# С того же компьютера
curl http://localhost:8889/users

# С другого компьютера в сети (после резервации)
curl http://IP-адрес-сервера:8889/users
```
