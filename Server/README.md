# 🎮 Покерный Сервер

Сервер для онлайн-игры в покер. Обрабатывает подключения клиентов и синхронизирует состояние игры между всеми участниками.

## 📋 Требования

- .NET 8.0 или выше (совместимо с .NET 6.0+)
- Windows, Linux или macOS

## 🚀 Запуск сервера

### Вариант 1: Через Visual Studio / Rider

1. Откройте проект `PokerServer.csproj` в вашей IDE
2. Нажмите F5 для запуска

### Вариант 2: Через командную строку

```bash
cd Server
dotnet build
dotnet run
```

### Вариант 3: Указать порт

```bash
dotnet run -- 9999
```

## ⚙️ Настройки

По умолчанию сервер запускается на порту **8888**.

Вы можете изменить порт:
- Через аргументы командной строки: `dotnet run -- 9999`
- Или изменив значение в `Program.cs`

## 📡 Протокол

Сервер использует TCP соединения и JSON для обмена сообщениями.

### Сообщения от клиента:

**Присоединение к игре:**
```json
{
  "type": "join",
  "name": "Имя игрока",
  "stack": 1000
}
```

**Действие игрока:**
```json
{
  "type": "action",
  "action": "fold|call|check|raise|bet",
  "amount": 100
}
```

**Запрос состояния игры:**
```json
{
  "type": "get_state"
}
```

### Сообщения от сервера:

**Подтверждение присоединения:**
```json
{
  "type": "join_success",
  "client_id": "уникальный_идентификатор",
  "player_name": "Имя игрока"
}
```

**Обновление списка игроков:**
```json
{
  "type": "players_update",
  "players": "Игрок1,Игрок2,Игрок3",
  "count": 3
}
```

**Начало раздачи:**
```json
{
  "type": "hand_start",
  "dealer_index": 0,
  "small_blind": 10,
  "big_blind": 20
}
```

**Карты игрока:**
```json
{
  "type": "hole_cards",
  "card1": "card_0",
  "card2": "card_1"
}
```

**Действие игрока:**
```json
{
  "type": "player_action",
  "player_name": "Имя игрока",
  "action": "fold",
  "amount": 0
}
```

**Состояние игры:**
```json
{
  "type": "game_state",
  "hand_active": true,
  "phase": "preflop|flop|turn|river|showdown",
  "current_bet": 20,
  "pot": 30,
  "community_cards": "card1,card2,card3"
}
```

## 🔧 Разработка

### Структура проекта:

- `Program.cs` - точка входа, запуск сервера
- `PokerServer.cs` - основной класс сервера
- `ClientConnection.cs` - обработка подключения клиента
- `GameSession.cs` - игровая сессия (стол)

### Добавление новых функций:

1. Добавьте новый тип сообщения в `PokerServer.cs`
2. Обработайте сообщение в `ClientConnection.ProcessMessage()`
3. Обновите логику игры в `GameSession.cs`
4. Обновите документацию

## 🐛 Отладка

Сервер выводит все важные события в консоль:
- ✅ Подключение клиентов
- 📨 Получение сообщений
- 🎯 Действия игроков
- ❌ Ошибки

## 📝 Примечания

- Максимум 6 игроков за столом
- Игра начинается автоматически при наличии 2+ игроков
- Сервер упрощен для демонстрации, в продакшене нужна дополнительная валидация и безопасность
