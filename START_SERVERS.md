# Порядок запуска серверов

## Важно понимать

**Порядок запуска НЕ влияет на ошибку "Отказано в доступе"** - это проблема прав доступа Windows, а не порядка запуска.

## Два независимых сервера

1. **PokerServer** (порт 8888) - игровой сервер для покера
2. **SyncServer** (порт 8889) - сервер синхронизации пользователей

Они могут работать **независимо**, но для синхронизации данных нужны **оба**.

## Сценарии использования

### Сценарий 1: Только игровой сервер (без синхронизации)

```bash
cd Server
dotnet run
```

Пользователи будут храниться только локально на этом сервере.

### Сценарий 2: Игровой сервер + синхронизация

**Шаг 1:** Запустите сервер синхронизации (в отдельном окне терминала):

```bash
cd Server\SyncServer
dotnet run -- --port 8889 --key "ваш-ключ"
```

**Шаг 2:** Запустите игровой сервер с синхронизацией (в другом окне):

```bash
cd Server
set POKER_SYNC_URL=http://localhost:8889
set POKER_SYNC_API_KEY=ваш-ключ
dotnet run --sync-env
```

### Сценарий 3: Только сервер синхронизации (для централизованного хранения)

Можно запустить только SyncServer на отдельном компьютере, а игровые серверы будут подключаться к нему.

## Решение проблемы "Отказано в доступе"

Эта ошибка **не связана с порядком запуска**. Это проблема прав Windows для HttpListener.

### Быстрое решение:

**Вариант 1:** Используйте другой порт (выше 1024, например 9000):
```bash
cd Server\SyncServer
dotnet run -- --port 9000 --key "piska"
```

Затем в игровом сервере укажите этот порт:
```bash
set POKER_SYNC_URL=http://localhost:9000
```

**Вариант 2:** Резервация URL для localhost (от имени администратора):
```powershell
netsh http add urlacl url=http://localhost:8889/ user=Everyone
```

**Вариант 3:** Запуск от имени администратора

**Вариант 4:** Попробуйте сначала запустить обычный сервер, чтобы убедиться, что с ним все в порядке, а потом уже настраивать синхронизацию

## Рекомендуемый порядок (для синхронизации)

1. **Сначала** запустите SyncServer (порт 8889)
2. **Затем** запустите PokerServer с включенной синхронизацией (порт 8888)

Но это нужно только для того, чтобы синхронизация работала. Для решения ошибки доступа это не поможет.

## Проверка

После запуска обоих серверов:
- SyncServer должен показать: "🌐 Сервер синхронизации запущен на порту 8889"
- PokerServer должен показать: "☁️ Облачная синхронизация: http://localhost:8889"

Если видите ошибку "Отказано в доступе" - это проблема прав, решайте её одним из способов выше.
