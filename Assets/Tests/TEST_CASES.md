- Все тест-кейсы должны выполняться в изолированной тестовой среде
- Перед выполнением тестов рекомендуется очистить данные тестовых пользователей
- Тесты с идентификаторами TC001-TC020 являются позитивными (проверяют корректную работу)
- Тесты с идентификаторами TC101-TC114 являются негативными (проверяют обработку ошибок)
- Тесты с идентификаторами TC201-TC208 являются деструктивными (проверяют устойчивость системы)
- Статус "Пройдено" означает, что фактический результат соответствует ожидаемому
- Статус "Провалено" означает, что фактический результат не соответствует ожидаемому
- Статус "Блокирован" означает, что тест не может быть выполнен из-за блокирующих проблем
