# Покрытие тестами покерной игры

## Обзор

Этот проект содержит полное покрытие юнит-тестами для покерной игры. Все тесты написаны с использованием NUnit Framework и Unity Test Framework.

   - Проверка всех 52 уникальных карт

2. **CardTypesExtendedTests.cs** - Расширенные тесты для CardTypes

3. **DeckTests.cs** - Тесты для колоды карт

4. **DeckExtendedTests.cs** - Расширенные тесты для Deck

## Запуск тестов

### В Unity Editor

1. Откройте Unity Editor
2. Перейдите в меню `Window > General > Test Runner`
3. Выберите вкладку `EditMode`
4. Нажмите `Run All` для запуска всех тестов

### Через командную строку

```bash
Unity -runTests -batchmode -projectPath "путь/к/проекту" -testResults "результаты.xml"
```

## Примечания

- Все тесты используют паттерн Arrange-Act-Assert (AAA)
- Тесты изолированы друг от друга
- Используются SetUp и TearDown для подготовки и очистки данных
- Тесты для классов, зависящих от Unity, используют моки и заглушки где необходимо

## Добавление новых тестов

При добавлении новых тестов следуйте этим правилам:

1. Используйте пространство имен `Tests`
2. Используйте атрибут `[Test]` для тестовых методов
3. Используйте `[SetUp]` и `[TearDown]` для подготовки и очистки
4. Следуйте паттерну AAA (Arrange-Act-Assert)
5. Используйте понятные имена тестов, описывающие что тестируется
6. Добавьте комментарии для сложных тестов

## Пример теста

```csharp
[Test]
public void ClassName_MethodName_ExpectedBehavior()
{
    // Arrange
    var instance = new ClassName();
    
    // Act
    var result = instance.MethodName();
    
    // Assert
    Assert.IsNotNull(result);
    Assert.AreEqual(expectedValue, result);
}
```
