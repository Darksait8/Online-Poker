# Исправление интеграции пользователей

## Проблема

Пользователи не видели друг друга и не могли взаимодействовать, потому что:
1. При подключении к игре использовалось имя из полей ввода, а не из авторизованного пользователя
2. Баланс не синхронизировался с серверным профилем

## Исправления

### 1. PokerClient.SendJoinRequest()
Теперь использует имя и баланс из авторизованного пользователя (`AuthManager.CurrentUser`), если пользователь авторизован.

### 2. ConnectionManager.UpdateClientSettings()
Теперь устанавливает имя и баланс из авторизованного пользователя в `PokerClient` перед подключением.

### 3. ConnectionManager.LoadSettings()
Теперь загружает имя и баланс из авторизованного пользователя при загрузке настроек.

## Как это работает теперь

1. **Пользователь авторизуется** через `AuthServerSync` → данные сохраняются в `AuthManager.CurrentUser`
2. **При подключении к игре** `PokerClient` автоматически использует:
   - Имя: `AuthManager.CurrentUser.username`
   - Баланс: `AuthManager.CurrentUser.chips`
3. **Сервер получает** правильное имя пользователя и баланс
4. **Все игроки видят друг друга** через `players_update` сообщения

## Проверка

После этих изменений:
- ✅ Все игроки должны видеть друг друга в списке игроков
- ✅ Имена должны совпадать с именами из серверных аккаунтов
- ✅ Баланс должен синхронизироваться с сервером

## Важно

- Убедитесь, что пользователь авторизован перед подключением к игре
- Если пользователь не авторизован, будет использоваться имя из полей ввода
- Баланс обновляется на сервере при обновлении профиля через `AuthServerSync.SyncProfileToServer()`
