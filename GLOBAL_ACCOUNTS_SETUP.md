# Настройка глобальных аккаунтов

Теперь аккаунты пользователей синхронизируются через сервер, что позволяет использовать один и тот же аккаунт на разных устройствах.

## Как это работает

1. **Сервер хранит все аккаунты** в файле `users.json` в папке `Server`
2. **Клиенты подключаются к серверу** для регистрации и входа
3. **Аккаунты доступны на всех устройствах**, подключенных к одному серверу

## Настройка

### 1. Запустите сервер

```bash
cd Server
dotnet run
```

Сервер автоматически создаст файл `users.json` для хранения аккаунтов.

### 2. Настройте клиент

В Unity:
1. Найдите объект с компонентом `AuthServerSync` в сцене авторизации
2. Установите `Server Host` на IP-адрес сервера (например, `192.168.1.100`)
3. Установите `Server Port` на `8888` (или другой порт, если изменили)
4. Убедитесь, что `Use Server Auth` включен

### 3. Автоматическая настройка

Если `AuthServerSync` не найден в сцене, он будет создан автоматически при первом запуске.

## Использование

### Регистрация

1. Запустите игру
2. Нажмите "Регистрация"
3. Введите имя пользователя, email и пароль
4. Аккаунт будет создан на сервере и доступен на всех устройствах

### Вход

1. Запустите игру
2. Введите имя пользователя и пароль
3. Если аккаунт существует на сервере, вы войдете в систему

## Важные замечания

- **Пароли хранятся в зашифрованном виде** на сервере (SHA256)
- **Локальные копии профилей** сохраняются для офлайн-доступа
- **Синхронизация баланса** происходит автоматически при обновлении профиля
- **Если сервер недоступен**, игра переключится на локальную авторизацию

## Устранение неполадок

### Не могу войти в аккаунт

1. Проверьте, что сервер запущен
2. Убедитесь, что IP-адрес сервера указан правильно
3. Проверьте, что порт `8888` открыт в firewall
4. Проверьте логи сервера на наличие ошибок

### Аккаунт не синхронизируется

1. Убедитесь, что `Use Server Auth` включен в `AuthServerSync`
2. Проверьте подключение к серверу (должно быть сообщение "✅ Подключен к серверу авторизации")
3. Проверьте логи Unity на наличие ошибок

### Файл users.json

Файл `Server/users.json` содержит все аккаунты. **Не удаляйте его**, если хотите сохранить данные пользователей.

## Миграция существующих аккаунтов

Если у вас уже есть локальные аккаунты:

1. Запустите сервер
2. Зарегистрируйте аккаунты заново через сервер (с теми же именами пользователей)
3. Локальные данные будут синхронизированы с сервером

## Безопасность

- Пароли никогда не передаются в открытом виде
- Все пароли хешируются с помощью SHA256
- Соединение происходит через TCP (для HTTPS потребуется дополнительная настройка)

## Резервное копирование

Регулярно делайте резервные копии файла `Server/users.json` для сохранения данных пользователей.
