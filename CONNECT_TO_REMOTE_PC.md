# 🌐 Подключение к серверу на другом ПК

Инструкция по подключению к серверу, который запущен на вашем ПК.

## 📋 Шаг 1: Узнайте IP-адрес сервера

### На ПК с сервером (где запущен сервер):

**Способ 1: Через ipconfig**
```cmd
ipconfig
```

Ищите **IPv4 Address** в разделе активного сетевого адаптера:
- Обычно это `192.168.x.x` (локальная сеть)
- Или `26.179.39.133` (если используете Radmin VPN)

**Способ 2: Сервер покажет IP при запуске**

После запуска `dotnet run` сервер автоматически покажет доступные IP-адреса:
```
🎮 Покерный сервер запущен на порту 8888
Ожидание подключений...

📡 Доступные IP-адреса для подключения:
   - 192.168.0.121 (для подключения используйте этот IP)
   - localhost или 127.0.0.1 (только для локального подключения)
```

## 🎮 Шаг 2: Настройка клиента в Unity

### Вариант A: Через UI (ConnectionManager)

1. **В Unity найдите ConnectionManager** в сцене
2. **В Inspector или в игре:**
   - Поле **"Server Host Input"** → введите IP-адрес сервера
     - `192.168.0.121` - для локальной сети
     - `26.179.39.133` - если используете Radmin VPN
   - Поле **"Server Port Input"** → `8888`
3. **Нажмите "Подключиться"**

### Вариант B: Через код

```csharp
var connectionManager = FindObjectOfType<ConnectionManager>();
if (connectionManager != null)
{
    // Используйте IP-адрес вашего ПК-сервера
    connectionManager.SetServerAddress("192.168.0.121", 8888);
    connectionManager.ConnectToServer();
}
```

## 🔥 Шаг 3: Настройка файрвола

### На ПК с сервером (ОБЯЗАТЕЛЬНО!):

**Windows:**
1. Откройте **Панель управления** → **Система и безопасность** → **Брандмауэр Windows**
2. Нажмите **Дополнительные параметры**
3. Выберите **Правила для входящих подключений** → **Создать правило**
4. Выберите **Порт** → **TCP** → **Определенные локальные порты**: `8888`
5. Выберите **Разрешить подключение**
6. Примените правило для всех профилей
7. Назовите правило: "Poker Server"

**Или через командную строку (от имени администратора):**
```cmd
netsh advfirewall firewall add rule name="Poker Server" dir=in action=allow protocol=TCP localport=8888
```

## ✅ Проверка подключения

### На сервере (ПК с сервером):

После подключения клиента вы должны увидеть:
```
✅ Новый клиент подключен. Всего клиентов: 1
```

### В Unity (на клиенте):

В Console должно появиться:
```
🔌 Попытка подключения к 192.168.0.121:8888...
✅ Подключен к серверу 192.168.0.121:8888
```

## 🐛 Решение проблем

### ❌ "Connection refused" или "Сервер недоступен"

**Проверьте:**

1. **Сервер запущен?**
   - На ПК с сервером должно быть окно с `dotnet run`
   - Должно быть сообщение "Ожидание подключений..."

2. **Правильный IP-адрес?**
   - Используйте IP из `ipconfig` на ПК с сервером
   - НЕ используйте `localhost` - это работает только на том же компьютере

3. **Файрвол настроен?**
   - На ПК с сервером должен быть открыт порт 8888
   - Попробуйте временно отключить файрвол для теста

4. **Оба устройства в одной сети?**
   - Для локальной сети: оба ПК должны быть в одной Wi-Fi/сети
   - Для Radmin VPN: оба ПК должны быть подключены к VPN

### ❌ "Timeout" или "Превышено время ожидания"

**Решение:**
- Проверьте IP-адрес (может быть неправильный)
- Проверьте, что оба устройства в одной сети
- Проверьте файрвол на ПК с сервером

### ❌ Сервер не видит подключений

**Решение:**
- Убедитесь, что сервер слушает на `0.0.0.0` (все интерфейсы)
- Проверьте файрвол на ПК с сервером
- Проверьте, что порт 8888 не занят другим приложением

## 💡 Полезные советы

1. **Для локальной сети:**
   - Используйте IP `192.168.x.x` из `ipconfig`
   - Оба ПК должны быть в одной Wi-Fi сети

2. **Для Radmin VPN:**
   - Используйте IP `26.179.39.133` (ваш VPN IP)
   - Оба ПК должны быть подключены к Radmin VPN

3. **Для интернета:**
   - Нужно настроить проброс портов на роутере
   - Используйте внешний IP-адрес

4. **Тестирование:**
   - Сначала проверьте подключение с того же ПК (`localhost`)
   - Затем попробуйте с другого устройства

## 📝 Чек-лист

Перед подключением убедитесь:

- [ ] Сервер запущен на ПК-сервере (`dotnet run`)
- [ ] Сервер показывает "Ожидание подключений..."
- [ ] Файрвол на ПК-сервере разрешает порт 8888
- [ ] В Unity указан правильный IP-адрес (НЕ localhost)
- [ ] Порт указан правильно (8888)
- [ ] Оба устройства в одной сети (для локальной сети)

---

**После выполнения этих шагов подключение должно работать! 🎮**
