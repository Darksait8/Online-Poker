# 📦 Как поделиться проектом

Инструкция по передаче проекта другому человеку.

## 🎯 Варианты передачи

### Вариант 1: Через архив (самый простой) ⭐ РЕКОМЕНДУЕТСЯ

1. **Создайте архив проекта:**
   - Исключите папки: `Library/`, `Temp/`, `Logs/`, `build/`, `obj/`, `bin/`
   - Включите: `Assets/`, `ProjectSettings/`, `Packages/`, `Server/`, документацию

2. **Что нужно включить в архив:**
   ```
   ✅ Assets/              - все ресурсы и скрипты
   ✅ ProjectSettings/     - настройки проекта
   ✅ Packages/            - зависимости Unity
   ✅ Server/              - серверная часть
   ✅ *.md                 - документация
   ✅ .gitignore           - если есть
   ```

3. **Что НЕ нужно включать:**
   ```
   ❌ Library/             - генерируется Unity автоматически
   ❌ Temp/                - временные файлы
   ❌ Logs/                - логи
   ❌ build/                - скомпилированная игра
   ❌ obj/                 - временные файлы сборки
   ❌ bin/                 - скомпилированные файлы сервера
   ```

4. **Создание архива:**
   - Windows: Выделите нужные папки → ПКМ → "Отправить" → "Сжатая ZIP-папка"
   - Или используйте 7-Zip/WinRAR для лучшего сжатия

5. **Размер архива:** Обычно 50-200 МБ (зависит от ресурсов)

### Вариант 2: Через Git (для разработчиков)

1. **Создайте репозиторий на GitHub/GitLab:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/ваш-username/online-poker.git
   git push -u origin main
   ```

2. **Другой человек клонирует:**
   ```bash
   git clone https://github.com/ваш-username/online-poker.git
   ```

3. **Преимущества:**
   - Легко обновлять проект
   - История изменений
   - Бесплатно для публичных репозиториев

### Вариант 3: Через облачное хранилище

- **Google Drive / Яндекс.Диск / Dropbox:**
  1. Загрузите архив проекта
  2. Поделитесь ссылкой (с правом скачивания)
  3. Другой человек скачивает и распаковывает

- **Преимущества:**
  - Просто
  - Не нужен Git
  - Большой размер файлов

## 📋 Инструкция для получателя

### Что нужно установить:

1. **Unity Hub + Unity Editor**
   - Версия Unity должна совпадать (проверьте `ProjectSettings/ProjectVersion.txt`)
   - Обычно Unity 2021.3 LTS или новее

2. **.NET SDK 8.0+** (для сервера)
   - Скачать: https://dotnet.microsoft.com/download
   - Проверить: `dotnet --version`

### Шаги для открытия проекта:

1. **Распакуйте архив** в любую папку

2. **Откройте Unity Hub:**
   - Нажмите "Add" или "Добавить"
   - Выберите папку с проектом
   - Unity автоматически определит версию

3. **Откройте проект:**
   - Дождитесь импорта ресурсов (может занять время)
   - Unity автоматически восстановит `Library/` и `Temp/`

4. **Для сервера:**
   ```bash
   cd Server
   dotnet restore
   dotnet build
   dotnet run
   ```

## 🔧 Проверка .gitignore

Убедитесь, что `.gitignore` содержит:

```

*.exe

```

## 📝 Чек-лист перед отправкой

- [ ] Проект компилируется без ошибок
- [ ] Сервер запускается (`dotnet run` в папке Server)
- [ ] Игра запускается в Unity
- [ ] Создан архив без `Library/`, `Temp/`, `build/`
- [ ] Включена документация (`ONLINE_SETUP.md`, `REMOTE_SERVER_SETUP.md`)
- [ ] Проверен размер архива (не слишком большой)

## 💡 Советы

1. **Минимальный размер:**
   - Исключите `Library/` и `Temp/` - это сэкономит 90% размера
   - Исключите `build/` если передаете исходники

2. **Если проект большой:**
   - Используйте Git LFS для больших файлов
   - Или разделите на несколько архивов

3. **Для быстрой передачи:**
   - Используйте торрент для больших файлов
   - Или облачное хранилище с быстрой загрузкой

4. **Безопасность:**
   - Не передавайте API ключи и пароли
   - Проверьте, что нет личных данных в проекте

## 🚀 Быстрый скрипт для создания архива (Windows)

Создайте файл `create-archive.bat`:

```batch
@echo off
echo Создание архива проекта...
powershell Compress-Archive -Path "Assets","ProjectSettings","Packages","Server","*.md",".gitignore" -DestinationPath "online-poker-project.zip" -Force
echo Готово! Архив создан: online-poker-project.zip
pause
```

Запустите его в корне проекта.

## 📞 Если что-то не работает

1. **Unity не открывает проект:**
   - Проверьте версию Unity в `ProjectSettings/ProjectVersion.txt`
   - Установите правильную версию через Unity Hub

2. **Ошибки компиляции:**
   - Убедитесь, что все скрипты на месте
   - Проверьте, что импортированы все ресурсы

3. **Сервер не запускается:**
   - Установите .NET SDK 8.0+
   - Выполните `dotnet restore` в папке Server
