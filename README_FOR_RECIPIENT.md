# 🎮 Инструкция для получателя проекта

Добро пожаловать! Это проект онлайн-покера на Unity.

## 📋 Что нужно установить

### 1. Unity Hub + Unity Editor
- Скачайте Unity Hub: https://unity.com/download
- Установите Unity Editor (версия указана в `ProjectSettings/ProjectVersion.txt`)
- Обычно требуется Unity 2021.3 LTS или новее

### 2. .NET SDK 8.0+ (для сервера)
- Скачайте: https://dotnet.microsoft.com/download
- Проверьте установку: `dotnet --version` (должно показать 8.0.x или выше)

## 🚀 Быстрый старт

### Шаг 1: Откройте проект в Unity

1. **Распакуйте архив** в любую папку (например, `C:\Projects\online-poker`)

2. **Откройте Unity Hub:**
   - Нажмите "Add" или "Добавить"
   - Выберите папку с проектом
   - Unity автоматически определит версию

3. **Откройте проект:**
   - Дождитесь импорта ресурсов (может занять 5-10 минут)
   - Unity автоматически восстановит папки `Library/` и `Temp/`

### Шаг 2: Запустите сервер

1. **Откройте терминал/командную строку:**
   - Windows: `Win + R` → `cmd` → Enter
   - Mac/Linux: Terminal

2. **Перейдите в папку Server:**
   ```bash
   cd путь/к/проекту/Server
   ```

3. **Запустите сервер:**
   ```bash
   dotnet restore
   dotnet build
   dotnet run
   ```

   Вы должны увидеть:
   ```
   🎮 Покерный сервер запущен на порту 8888
   Ожидание подключений...
   ```

### Шаг 3: Запустите игру

1. **В Unity:**
   - Откройте сцену `Main` (или другую игровую сцену)
   - Нажмите Play ▶️

2. **Подключитесь к серверу:**
   - Если есть меню подключения, введите:
     - IP сервера: `localhost` (если сервер на том же компьютере)
     - Порт: `8888`
   - Или используйте код из `ONLINE_SETUP.md`

## ❓ Решение проблем

### Unity не открывает проект

**Проблема:** Ошибка версии Unity

**Решение:**
1. Проверьте версию в `ProjectSettings/ProjectVersion.txt`
2. Установите правильную версию через Unity Hub
3. Откройте проект снова

### Ошибки компиляции в Unity

**Проблема:** Красные ошибки в Console

**Решение:**
1. Дождитесь полного импорта ресурсов
2. Проверьте, что все скрипты на месте в `Assets/Scripts/`
3. Попробуйте: `Assets` → `Reimport All`

### Сервер не запускается

**Проблема:** `dotnet: command not found` или ошибка версии

**Решение:**
1. Установите .NET SDK 8.0+: https://dotnet.microsoft.com/download
2. Проверьте: `dotnet --version`
3. Выполните: `dotnet restore` в папке Server

### Игра не подключается к серверу

**Проблема:** Ошибка подключения

**Решение:**
1. Убедитесь, что сервер запущен
2. Проверьте IP-адрес (используйте `localhost` для локального сервера)
3. Проверьте порт (должен быть `8888`)
4. Проверьте файрвол (может блокировать соединение)

## 💡 Полезные советы

- **Первая загрузка:** Unity может долго импортировать ресурсы - это нормально
- **Размер проекта:** После импорта папка `Library/` может быть большой (1-5 ГБ)
- **Сервер:** Может работать на том же компьютере или на другом устройстве
- **Тестирование:** Можно запустить несколько экземпляров Unity для тестирования
