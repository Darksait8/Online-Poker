# 🌐 Настройка удаленного сервера

Это руководство поможет вам настроить игру с сервером на другом устройстве (компьютере, ноутбуке и т.д.).

## 📋 Шаг 1: Запуск сервера на удаленном устройстве

### На устройстве-сервере:

1. **Скопируйте папку `Server`** на это устройство
2. **Установите .NET 8.0+** (если еще не установлен, совместимо с .NET 6.0+)
3. **Запустите сервер:**

```bash
cd Server
dotnet build
dotnet run
```

Сервер запустится и будет ждать подключений.

## 🔍 Шаг 2: Узнайте IP-адрес сервера

### Windows:
```cmd
ipconfig
```
Ищите строку **IPv4 Address** в разделе вашего сетевого адаптера (обычно что-то вроде `192.168.1.100`)

### Linux/Mac:
```bash
ifconfig
# или
ip addr
```
Ищите `inet` адрес (обычно начинается с `192.168.` или `10.`)

### Альтернативный способ:
- Запустите сервер
- В консоли сервера будет показан IP-адрес, на котором он слушает

## 🎮 Шаг 3: Настройка клиента в Unity

### Вариант A: Через UI (ConnectionManager)

1. **В Unity Editor:**
   - Найдите объект с `ConnectionManager` в сцене
   - В поле **Server Host Input** введите IP-адрес сервера (например: `192.168.1.100`)
   - Порт оставьте `8888` (или тот, который использует сервер)
   - Нажмите "Подключиться"

2. **В игре:**
   - Откройте меню подключения
   - Введите IP-адрес сервера вместо `localhost`
   - Нажмите "Подключиться"

### Вариант B: Через код

```csharp
var networkManager = FindObjectOfType<NetworkGameManager>();
if (networkManager != null)
{
    // Замените "192.168.1.100" на реальный IP-адрес сервера
    networkManager.EnableOnlineMode("192.168.1.100", 8888);
}
```

### Вариант C: Через ConnectionManager программно

```csharp
var connectionManager = FindObjectOfType<ConnectionManager>();
if (connectionManager != null)
{
    // Установите IP-адрес через код
    var hostInput = GameObject.Find("ServerHostInput")?.GetComponent<TMP_InputField>();
    if (hostInput != null)
    {
        hostInput.text = "192.168.1.100"; // IP вашего сервера
    }
    connectionManager.ConnectToServer();
}
```

## 🔥 Шаг 4: Настройка файрвола

### Windows:

1. Откройте **Панель управления** → **Система и безопасность** → **Брандмауэр Windows**
2. Нажмите **Дополнительные параметры**
3. Выберите **Правила для входящих подключений** → **Создать правило**
4. Выберите **Порт** → **TCP** → **Определенные локальные порты**: `8888`
5. Разрешите подключение
6. Примените правило

### Linux (ufw):

```bash
sudo ufw allow 8888/tcp
sudo ufw reload
```

### Mac:

1. Системные настройки → Защита и безопасность → Брандмауэр
2. Нажмите "Параметры"
3. Добавьте правило для порта 8888

## 🌍 Шаг 5: Игра через интернет (опционально)

Для игры через интернет нужно:

### 1. Узнать внешний IP-адрес сервера:
- Зайдите на сайт [whatismyip.com](https://whatismyip.com) с устройства-сервера
- Запишите показанный IP-адрес

### 2. Настроить проброс портов на роутере:

1. Зайдите в настройки роутера (обычно `192.168.1.1` или `192.168.0.1`)
2. Найдите раздел **Port Forwarding** или **Виртуальные серверы**
3. Добавьте правило:
   - **Внешний порт**: `8888`
   - **Внутренний IP**: IP-адрес устройства-сервера в локальной сети
   - **Внутренний порт**: `8888`
   - **Протокол**: TCP

### 3. В клиенте использовать внешний IP:

Вместо локального IP используйте внешний IP-адрес сервера.

⚠️ **Внимание:** Открытие портов в интернет создает риски безопасности. Используйте только для тестирования или добавьте шифрование и аутентификацию.

## ✅ Проверка подключения

### На сервере:
Вы должны увидеть сообщение:
```
✅ Новый клиент подключен. Всего клиентов: 1
```

### В Unity (Console):
```
🔌 Подключен к серверу 192.168.1.100:8888
✅ Успешно присоединился как [Ваше имя]
```

## 🐛 Решение проблем

### Клиент не может подключиться

1. **Проверьте, что сервер запущен:**
   - На сервере должна быть консоль с сообщением "Ожидание подключений..."

2. **Проверьте IP-адрес:**
   - Убедитесь, что используете правильный IP
   - Попробуйте `ping [IP-адрес]` с клиента

3. **Проверьте файрвол:**
   - Убедитесь, что порт 8888 открыт на сервере
   - Попробуйте временно отключить файрвол для теста

4. **Проверьте сеть:**
   - Оба устройства должны быть в одной сети (для локальной игры)
   - Или иметь доступ к интернету (для удаленной игры)

### "Connection refused" или "Timeout"

- Сервер не запущен или недоступен
- Неправильный IP-адрес или порт
- Файрвол блокирует соединение
- Устройства не в одной сети

### Сервер не видит подключений

- Проверьте, что сервер слушает на `0.0.0.0` (все интерфейсы), а не только `localhost`
- В коде сервера используется `IPAddress.Any`, что правильно

## 💡 Полезные советы

1. **Для тестирования на одном компьютере:**
   - Используйте `localhost` или `127.0.0.1`
   - Можно запустить несколько экземпляров Unity для тестирования

2. **Для локальной сети:**
   - Используйте локальный IP (обычно `192.168.x.x` или `10.x.x.x`)
   - Убедитесь, что оба устройства в одной Wi-Fi сети

3. **Для стабильности:**
   - Используйте проводное соединение для сервера
   - Убедитесь в стабильности интернет-соединения

4. **Безопасность:**
   - Не открывайте порты в интернет без необходимости
   - Используйте VPN для безопасного подключения
   - Добавьте аутентификацию для продакшена

## 📝 Примеры IP-адресов

- **Локальный компьютер:** `localhost` или `127.0.0.1`
- **Локальная сеть:** `192.168.1.100` (замените на ваш IP)
- **Интернет:** `123.45.67.89` (внешний IP сервера)
