# Инструкция по перезапуску сервера

## Проблема

Если сервер не распознает сообщения `auth_login` или `auth_register`, это означает, что сервер был запущен со старым кодом.

## Решение

### 1. Остановите текущий сервер

Нажмите `Ctrl+C` в окне CMD, где запущен сервер.

### 2. Пересоберите сервер

```bash
cd Server
dotnet build
```

### 3. Запустите сервер заново

```bash
dotnet run
```

### 4. Проверьте вывод

При запуске вы должны увидеть:
- ✅ Сообщение о запуске сервера
- 📂 Сообщение о загрузке базы данных пользователей (если файл `users.json` существует)

### 5. Попробуйте подключиться снова

После перезапуска сервер должен правильно обрабатывать запросы авторизации.

## Важно

- **Всегда перезапускайте сервер** после изменения кода
- Убедитесь, что используете правильную версию .NET (8.0)
- Проверьте, что файл `Server/users.json` существует (он создается автоматически)

## Проверка работы

После перезапуска при попытке входа вы должны увидеть в консоли сервера:
```
📨 Получено сообщение от [имя]: auth_login
🔐 Попытка входа: [имя пользователя]
✅ Пользователь вошел в систему: [имя пользователя]
```

Если видите "⚠️ Неизвестный тип сообщения: auth_login", значит сервер все еще использует старый код - пересоберите и перезапустите.
